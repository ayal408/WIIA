🎮 Wii Homebrew Games

12 משחקי הומברו מקוריים ל-Wii, שנכתבו ב-C עם devkitPro. משתמשים ב-Wii Remote (מצביע IR, תאוצה, כפתורים) וב-Wii Balance Board. רצים על Wii אמיתי עם Homebrew Channel, או באמולטור Dolphin.

הערת זכויות יוצרים: כל המשחקים כאן מקוריים ונכתבו במיוחד לריפו הזה. אין כאן קבצי ROM/ISO של משחקים מסחריים ואין הוראות להשגתם.
קוד המקור ב-GitHub מדריך "איך משחקים" מלא בניות אוטומטיות (Actions)

איך משחקים בפועל על ה-Wii

  1. בטאב Actions בריפו, פתחו את ה-run האחרון שהצליח (סימן ✓ ירוק) והורידו את ה-artifact בשם wii-usb-apps.
  2. חלצו את ה-zip - תקבלו תיקיית apps מוכנה, עם תת-תיקייה לכל משחק.
  3. העתיקו את תיקיית apps לשורש כרטיס SD או USB (כך שיהיה SD:/apps/...).
  4. הכניסו את הכרטיס ל-Wii, פתחו את ה-Homebrew Channel - כל משחק יופיע ברשימה עם שם ותיאור.
